# Navera at Mayfield Village

Independent information and Priority Access registration site for Navera at Mayfield Village in Brampton. Not the official website of Digreen Homes.

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and set the Supabase anon key before submitting the registration form. Registrations insert into the existing `navera_homes_leads` table.
